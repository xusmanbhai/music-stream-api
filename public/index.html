📡 API Endpoints Reference
  • GET
    /search?song=<name>
    Search YouTube — returns top 5 tracks as JSON
    { id, title, duration, thumbnail, url, channel, views }
  • POST
    /search
    Same as GET /search — body: { "song": "name" }
    Handy for mobile apps using fetch/axios POST.
  • GET
    /play?url=<youtube_url>
    Streams audio directly — pipe into <audio> src or mobile player.
    Content-Type: audio/webm; codecs=opus
  • GET
    /info?url=<youtube_url>
    Full metadata for one video: title, description, views, likes, channel, etc.
  • GET
    /health
    Server status + uptime check.
⚡ Usage Examples

Copy-paste these into your React Native / Web app:

JavaScript / React Native — Search

const BASE = 'http://localhost:3000'; // Search for a song const res = await fetch(`${BASE}/search?song=Blinding+Lights`); const data = await res.json(); // data.results → array of { id, title, duration, thumbnail, url } // POST variant (for mobile apps) const res2 = await fetch(`${BASE}/search`, { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ song: 'Bohemian Rhapsody' }) }); const data2 = await res2.json();

React Native — Audio Playback (expo-av)

import { Audio } from 'expo-av'; const BASE = 'http://YOUR_SERVER_IP:3000'; async function playTrack(youtubeUrl) { const { sound } = await Audio.Sound.createAsync( { uri: `${BASE}/play?url=${encodeURIComponent(youtubeUrl)}` }, { shouldPlay: true } ); return sound; } // Usage: const sound = await playTrack('https://www.youtube.com/watch?v=VIDEO_ID');

HTML — Stream in <audio> tag

<audio controls src="http://localhost:3000/play?url=https://www.youtube.com/watch?v=VIDEO_ID"></audio>
